## Differenze dal prototipo

Rimossi fixture, esiti simulati, pannello demo e anteprima messaggio.
API autentica, stock verificato, eventi reali, chat reale alla pressione della
cliente. Nessun messaggio viene inviato automaticamente.
Il filtro globale misura è rinviato: manca il dato nella API lista;
roller disponibile nella scheda. Nessun contatore foto inventato nella griglia.

## Limiti espliciti

Il collaudo locale usa risposte simulate conformi al contratto reale; non è
una prova di autenticazione Telegram, consegna notifiche o stock reale.
Non è stata svolta una prova fisica iPhone/VoiceOver. Nessun test cliente
o richiesta commerciale reale è stato creato.
Le immagini usano gli asset pubblici già approvati: derivati responsive
e cache/media pipeline restano separati da questo rilascio frontend.
